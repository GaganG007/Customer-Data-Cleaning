# Customer Data Cleaning (pandas)

Cleaned a messy customer call list so it's ready for a call campaign.

## What I did
- Removed duplicates and a useless column
- Standardized Yes/No values to Y/N
- Cleaned and formatted phone numbers (123-456-7890)
- Split Address into Street Address, State and Zip Code
- Removed customers marked Do Not Contact and rows with no phone number

## Files
- `Customer Call List.xlsx`: raw data
- `Customer_Clean_Data.ipynb`: cleaning steps
- `customer_list_clean.csv`: final result

## Tools
Python, pandas
